# Лабораторная работа 5 «Список товаров с фильтрами»

React + Vite, данные с https://fakestoreapi.com. Ключи не нужны.

## Как запустить (Windows)

Нужен Node.js 18 или новее: https://nodejs.org (версия LTS).

Откройте папку проекта в терминале (в VS Code: Терминал → Новый терминал) и выполните:

```
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).


## Что сделано

- Загрузка товаров через `fetch` в `useEffect`, отмена запроса при размонтировании (`AbortController`), проверка `res.ok`.
- Состояния: `loading`, `error`, `products`, `filteredProducts`, `filters`.
- Фильтрация на клиенте во втором `useEffect` (по категориям и диапазону цены).
- Валидация по кнопке «Применить»: отрицательная цена, «от» > «до»; поле с ошибкой подсвечивается красным, ошибка сбрасывается при исправлении.
- **Самостоятельная работа 1:** выбор нескольких категорий (чекбоксы, массив в `useState`).
- **Самостоятельная работа 2:** ползунки (`range input`) для минимальной и максимальной цены, синхронизированы с полями ввода.
- Фото товаров из поля `image` (fakestoreapi); если фото нет или оно не загрузилось — заглушка через Data URI.
- Кнопка «Сбросить» и счётчик найденных товаров.
